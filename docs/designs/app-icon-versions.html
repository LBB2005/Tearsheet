The new app icon: four versions

Your pick (Nov 5): 2. Glass. You picked the glass tile from the setup mockup over the Fan. What you decided:

  • Everywhere: the Dock and Finder icon, the welcome screen, the home page and the run view all use the new mark, so nothing still shows the Fan.
  • Four refined versions, each checked in the Dock, at Finder sizes down to 16 px, and inside the app.
  • Quiet motion: it fades up like everything else, and in the run view its rising line fills in as the 14 steps finish, then completes when the report is ready. The Dock’s progress bar stays as it is.

All four keep the same idea: a dark tile with lines of text and a rising price line. They differ in how much depth and detail they carry. The 16 and 32 px sizes use a simpler drawing of each, the way macOS icons do. Each version’s run line plays on its own; Play again restarts it.
