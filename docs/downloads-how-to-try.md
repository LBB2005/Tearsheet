# Report downloads: how to try them

1. Open any saved report and scroll to the end. Three buttons sit above the footer:
   **Download PDF**, **Download slide deck**, **Download Excel**.
2. Click one. A note at the bottom right says it's being made, then **Saved to Downloads**
   with **Show in Finder**. Each takes a second or two and uses no AI.
3. The first time a new build saves to Downloads, macOS asks whether Tearsheet may use your
   Downloads folder. Click **Allow**. (If you click Don't Allow, the note says where to turn it
   back on: System Settings → Privacy & Security → Files and Folders → Tearsheet.)

Files are named like `JPM Tearsheet 7 Nov 2026.pdf`; a second copy gets ` (2)`. They work for
every saved report, old ones too.

**What's in each**

* **PDF:** a bank-style company note. Page 1 is the summary (the call, key points, three
  exhibits, key data); then the full report, the numbers, the analysts' view, how it was checked,
  numbered sources with their quoted passages, and important information.
* **Slide deck:** 12 slides and a 5-slide appendix. Claims are copied whole, never cut.
* **Excel:** a classic bank model. Point at any blue number to see where it came from. The
  Sources & checks tab shows 15–22 checks; every one should read OK.

Every file says "Research data, not investment advice."
